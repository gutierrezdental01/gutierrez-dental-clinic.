GUTIERREZ DENTAL WEBSITE - GITHUB BRANCH UPDATE

Extract this ZIP and upload the files directly into the root of your new GitHub branch (not the ZIP itself).
No assets folder is used.

Includes index.html, styles.css and the three JPG images. Old script.js is no longer needed because the booking form has been replaced with a portal link and menu behavior is embedded in index.html.

IMPORTANT: Booking portal is a pilot. Do not accept real HMO documents until security and privacy controls are verified. Verify the Apps Script /exec?page=booking deployment has been updated and tested.

To publish a new branch, GitHub repository Settings > Pages > Deploy from a branch > choose that branch and /(root), then Save.
